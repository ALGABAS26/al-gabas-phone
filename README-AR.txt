تحديث الجباس استور: صفحة المنتج + إصلاح قيد التصنيف

1) ارفع محتويات هذا المجلد إلى جذر مستودع GitHub واستبدل الملفات المطابقة، ثم Commit changes.
2) صفحة المنتج أصبحت نافذة كاملة تغطي المتجر؛ زر «الرجوع للمتجر» يعيدك لمكانك السابق.
3) لحل خطأ قاعدة البيانات products_category_check، افتح Supabase Dashboard ثم SQL Editor، والصق محتوى FIX_SUPABASE_CATEGORY_CONSTRAINT.sql وشغّله مرة واحدة.
   هذا التعديل يزيل قائمة التصنيفات المقيدة القديمة ويسمح بأي اسم قسم نصّي غير فارغ. لا تشغّل الملف إن كنت تريد الاحتفاظ بقائمة تصنيفات محددة فقط.
4) احتفظ بملف config.js الحالي إن كانت إعدادات Supabase عندك مختلفة.
5) بعد النشر حدّث الموقع تحديثًا قويًا أو افتحه في نافذة خفية.

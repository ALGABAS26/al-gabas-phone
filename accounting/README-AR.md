# نظام حسابات الجباس فون – النسخة التأسيسية

## رابط التطبيق بعد تفعيل GitHub Pages
https://algabas26.github.io/al-gabas-phone/accounting/

## خطوات الإعداد
1. افتح مشروع Supabase الحالي.
2. من SQL Editor أنشئ Query جديداً.
3. انسخ محتوى schema.sql بالكامل وشغّله.
4. من Authentication > Settings عطّل تسجيل المستخدمين الجدد (Sign ups).
5. استخدم حساب المالك الحالي فقط.
6. تأكد أن config.js في جذر المشروع يحتوي على Project URL وPublishable/anon key فقط. ممنوع وضع service_role أو Secret Key في ملفات الواجهة.

## الموجود في النسخة التأسيسية
- تسجيل دخول Supabase.
- لوحة تأسيسية.
- إضافة المنتجات والمخزون.
- إنشاء باركود تلقائي لكل منتج.
- مسح باركود بالكاميرا في المتصفحات الداعمة BarcodeDetector.
- دعم قارئ USB الذي يعمل كلوحة مفاتيح من خلال خانة البحث.
- تصوير شاشة *#06# واستخراج IMEI عبر OCR مع مراجعة قبل الحفظ.
- التحقق من 15 رقماً وخوارزمية Luhn وقيود منع التكرار في قاعدة البيانات.
- سجل حركات ماكينة فوري والعمولات والرسوم.

## ملاحظات مهمة
- افتح التطبيق عبر HTTPS واسمح للمتصفح باستخدام الكاميرا.
- دعم BarcodeDetector يختلف حسب المتصفح؛ قارئ USB 2D بديل عملي.
- OCR قد يخطئ؛ راجع الرقم قبل الحفظ.
- رصيد فوري المعروض دفتري، ويجب مطابقة تأثير كل نوع حركة مع كشف وتسوية ماكينة فوري الفعلية قبل الاعتماد.
- هذه مرحلة تأسيسية وليست نظام حسابات مكتملاً بعد. لا تستخدمها للأرصدة الحقيقية قبل إضافة المبيعات والمشتريات والقيود المحاسبية واختبارها.
 
## التحديث الثاني: تقفيل فوري وقسم الصيانة
1. افتح ملف [upgrade-02.sql](upgrade-02.sql) وانسخ محتواه بالكامل.
2. في Supabase افتح SQL Editor ثم New query والصق الكود وشغّله مرة واحدة.
3. افتح التطبيق من جديد. ستجد قسم تقفيل ماكينة فوري وقسم الصيانة.
4. في فوري أدخل الافتتاحي والشحن والختامي والأرباح يدويًا من كشف اليوم. الشحن يسجل حركة خروج من الخزينة في جدول erp_cash_movements، ولا يُحسب مصروفًا.
5. رصيد اليوم التالي يُقترح تلقائيًا من آخر رصيد ختامي محفوظ. لا تعتمد التقفيل قبل مطابقته مع كشف الماكينة.

قسم الصيانة في هذه المرحلة يسجل أمر الاستلام وبيانات العميل والجهاز والعطل. تحديث الحالات والتكاليف والفواتير وربطها بالخزينة سيأتي في مرحلة لاحقة.


## ربط الخزنة بمصدر شحن فوري
بعد تشغيل `upgrade-02.sql` شغّل ملف `upgrade-03.sql` مرة واحدة من Supabase SQL Editor. سيضيف ثلاثة أرصدة مستقلة: درج الكاش، فودافون كاش، وإنستا باي. من صفحة «الخزنة والأرصدة» أدخل الرصيد الافتتاحي الفعلي لكل حساب. عند تقفيل فوري اختر مصدر الشحن؛ سيتم خصم المبلغ من الحساب المختار وتسجيل الحركة تلقائيًا. لا تدخل نفس الرصيد الافتتاحي في أكثر من حساب.

# إشعار جاهزية جهاز الصيانة عبر WhatsApp (مجهز وغير منشور)

تُستدعى الدالة بعد تحويل أمر صيانة مملوك للمستخدم الحالي إلى الحالة `ready`. تتحقق الدالة من جلسة المستخدم وملكية الأمر وحالته ورقم الهاتف قبل الاتصال بواتساب.

## أسرار الخادم المطلوبة
- `WA_SEND_ENABLED=false` حتى اكتمال الاختبارات والموافقة على تفعيل الإرسال
- `WA_ACCESS_TOKEN`
- `WA_PHONE_NUMBER_ID`
- `WA_MAINTENANCE_READY_TEMPLATE_NAME`: اسم قالب Meta معتمد بثلاثة متغيرات نصية في Body بالترتيب: اسم العميل، الجهاز، رقم أمر الصيانة
- `WA_TEMPLATE_LANGUAGE=ar`
- `WA_GRAPH_API_VERSION` (الافتراضي v25.0)
- أسرار Supabase الافتراضية: URL وpublishable/anon key وservice-role key

يجب مراجعة وتشغيل ملف SQL المقترح على قاعدة اختبار أولًا. سجل المحاولات فريد لكل أمر صيانة، ولا يعيد إرسال الحالات المقبولة أو الفاشلة أو غير المؤكدة تلقائيًا. لم يتم نشر الدالة ولم يتم إرسال أي رسالة حقيقية.
